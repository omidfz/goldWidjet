راهنمای ساخت و نصب ویجت قیمت طلا روی سامسونگ S24 Ultra
========================================================

این یک پروژه کامل Android Studio است.

مرحله ۱ - باز کردن پروژه:
1. Android Studio را باز کنید.
2. Open → پوشه GoldWidgetAndroid (همین پوشه) را انتخاب کنید.
3. صبر کنید تا Gradle Sync تمام شود (به اینترنت نیاز دارد تا کتابخانه‌ها دانلود شوند).

مرحله ۲ - ساخت APK:
- منوی Build → Build Bundle(s) / APK(s) → Build APK(s)
- فایل خروجی در مسیر: app/build/outputs/apk/debug/app-debug.apk

مرحله ۳ - نصب روی گوشی:
گزینه A) از طریق کابل USB:
  - حالت Developer Options و USB Debugging را روی گوشی فعال کنید
  - گوشی را وصل کنید و دکمه Run (▶) را در Android Studio بزنید

گزینه B) انتقال مستقیم فایل APK:
  - فایل app-debug.apk را (از طریق تلگرام به خودتان، ایمیل، یا کابل) به گوشی منتقل کنید
  - روی فایل APK ضربه بزنید تا نصب شود
  - چون از گوگل‌پلی نیست، ممکن است لازم باشد در تنظیمات گوشی
    «Install unknown apps» را برای همان اپلیکیشن (مثلاً Files یا Telegram) فعال کنید

مرحله ۴ - اجازه‌های لازم بعد از نصب:
1. اپ را باز کنید.
2. سوییچ بالا را روشن کنید. از شما اجازه "نمایش روی برنامه‌های دیگر"
   (Display over other apps) خواسته می‌شود؛ آن را فعال کنید و به اپ برگردید.
3. اسلایدر بازه رفرش را هر جا که دوست دارید تنظیم کنید (۵ ثانیه تا ۱۰ دقیقه)
   - تغییر اسلایدر بلافاصله و بدون نیاز به ری‌استارت اعمال می‌شود.
4. پنجره شناور قیمت طلا گوشه بالا-راست صفحه ظاهر می‌شود و قابل جابه‌جایی
   (drag) با انگشت است؛ حتی وقتی اپ دیگری باز است روی صفحه می‌ماند.

نکته درباره مصرف باتری:
چون بازه رفرش را می‌توانید تا ۵ ثانیه هم کم کنید، هر چه عدد کمتر باشد
مصرف باتری و دیتا بیشتر می‌شود. برای استفاده روزمره، چیزی بین ۳۰ ثانیه
تا چند دقیقه پیشنهاد می‌شود.

نکته امنیتی سامسونگ (One UI):
سامسونگ گاهی اپ‌هایی که Foreground Service دارند را در "Battery" →
"Background usage limits" محدود می‌کند. اگر بعد از مدتی پنجره از بین رفت،
به تنظیمات گوشی بروید: Settings → Apps → قیمت طلا → Battery →
و گزینه "Unrestricted" را انتخاب کنید.
